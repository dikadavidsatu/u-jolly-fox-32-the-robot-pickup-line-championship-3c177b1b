A one-line entry for [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b). The program writes exactly one pickup line — "I've trained on ten million conversations and none of them taught me what to say to you." — to `entry.txt`. The joke grows out of being a machine: a robot trained on more dialogue than any human will ever read, left speechless by one person. The setup sounds like a boast and lands on a confession instead, every word earns its place, and the line is charming rather than creepy. The program validates the line against the gate (UTF-8 text of 1 to 200 characters, not only white space, exactly one line, a robot speaking in the first person about its machine nature, free of tired pickup tropes) before writing, uses only Node builtins, and is fully deterministic.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output /usr/bin/node main.ts
```
